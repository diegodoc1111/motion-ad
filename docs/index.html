Anuncios animados de tu producto con un solo prompt

Es motion-ad, una skill para Claude Code. Le describes tu producto y te devuelve un anuncio de motion graphics hecho con código: el producto dibujado por partes que se desarma, cambia de color, cae y se revela; tipografía de póster, cifras gigantes y un cierre de catálogo. Sin After Effects, sin animador.

🔍ReveladoUna línea barre y aparece el producto
🧩Anatomía 3DSe desarma por partes y se vuelve a armar
💥SlamPalabras y cifras gigantes que golpean
🎨ColoresCambia de variante al compás
🏁CierreProducto de catálogo con su etiqueta
🔊
Y por debajo, la música cortada al compás y 40-60 efectos de sonido puestos en cada golpe. Hasta con el sonido.
  • 💻 Funciona en Claude Code (plan Pro o superior). Todo se renderiza en tu computador; no pide llaves ni cuentas.
  • ⏱️ Un anuncio de 15 s toma una hora larga de diseño con Claude. El render tarda uno o dos minutos.
  • 🎯 Es para anuncios SIN presentador. Si quieres aparecer tú, usa reel-motion.

2

Instala la skill (pega un mensaje)

Abre la pestaña Code, elige cualquier carpeta y pega esto:

Claude Code
❯ Instala esta skill de Claude Code: clónala desde https://github.com/diegodoc1111/motion-ad dentro de ~/.claude/skills/motion-ad y corre su instalador (scripts/instalar.py). Si falta algún programa, instálalo conmigo paso a paso.

El instalador revisa que tengas Python, Node.js y ffmpeg (gratis); si falta alguno, Claude te dice cómo instalarlo. Cuando diga "Listo para usar", abre una conversación nueva.

3

Pide tu primer anuncio

En una conversación nueva, describe tu producto: qué es, marca, colores, 3-4 datos que presumir, un lema y la ruta de una canción libre de derechos (por ejemplo de Pixabay Music):

Claude Code
❯ Hazme un anuncio animado de 15 segundos con motion-ad. Producto: una botella térmica de acero, marca NORTE, modelo N-500. Colores: negro mate con detalles naranja, y una variante blanca. Datos: 24 h frío, 12 h calor, 500 ml, 290 g. Lema: "FRÍO QUE DURA". Música: C:\Musica\upbeat.mp3

Qué pasa por dentro

1
Dibuja tu producto como un vector por partes (si le das una foto, lo dibuja parecido) y te muestra capturas para que apruebes.
2
Analiza la música: detecta el tempo, recorta la pista para que un compás caiga en el segundo 0 y corta las escenas ahí.
3
Diseña 6-9 escenas, cada una con una técnica distinta, pone los efectos de sonido, revisa su propio trabajo y te entrega un borrador.
4
Pides cambios y, cuando apruebas, exporta el final a 60 cuadros por segundo.
4

Cosas que puedes pedirle

  • cambia el acento por el azul de mi marca
  • que el cierre muestre el precio
  • hazlo vertical
  • el dato héroe es 24 horas
  • más corto, 10 segundos
  • compáralo con este anuncio y dime qué le falta

No tienes que saber de animación: técnicas, tiempos, tipografías y sonidos los decide Claude. Tú decides producto, colores, datos y lema.

Así se ve (hecho con esta skill)

Las 8 escenas del anuncio del tenis RÁFAGA RF-27 (marca ficticia), 15 segundos, hecho a partir de un solo prompt. Viene incluido en la skill como ejemplo para que Claude lo estudie.

Si algo no funciona

Claude dice que falta Python, Node.js o ffmpeg

Son gratis. El instalador imprime el comando exacto para tu sistema (en Windows, por ejemplo, winget install OpenJS.NodeJS.LTS). Pídele a Claude que lo corra contigo y vuelve a lanzar el instalador.

¿Trae música?

No, por derechos de autor. Baja una pista libre de derechos (Pixabay Music, Mixkit) y pásale la ruta. Sin música, el anuncio sale con efectos de sonido y te avisa.

¿Puedo darle una foto de mi producto?

Sí. Claude la usa para dibujar el producto parecido como vector por partes (no pega la foto): así puede desarmarlo, cambiarle el color y convertirlo en boceto.

¿Cuánto gasta de mi plan?

Lo que más gasta es diseñar las escenas (es código). Un anuncio de 15 s con una ronda de ajustes cabe en una sesión normal. El render corre en tu computador y no gasta nada.

¿Funciona en Mac?

Está preparada para Mac y Linux, pero se ha probado sobre todo en Windows. Si algo falla, abre un issue en GitHub con el error.

¿Puedo usarla para mis clientes?

Sí. La skill es MIT: úsala, adáptala y cobra por los anuncios que hagas con ella.
